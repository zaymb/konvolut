# konvolut

星座笔记。一个静态页面（`index.html`）加一份数据（`notes.json`），由 GitHub Pages 托管；页面直接通过 GitHub API 读写 `notes.json`。

## 卡片的数据格式

`notes.json` 是一个数组，一张卡一行。

| 字段 | 含义 |
| --- | --- |
| `id` | 编号，只增不改；正文里写 `#117` 会自动变成链接 |
| `k` | `lit`（别人的理论或作品，带出处）、`perm`（自己成形的论点）、`fleeting`（自己的念头，不引任何人） |
| `h` | 标题：一句话说出这张卡主张什么 |
| `t` | 正文，段落之间用 `\n` |
| `s` | 出处，只有 `lit` 用；没核实的细节后面标〔待核〕 |
| `g` | 标签 |
| `l` | 相连卡片的编号，两张卡上都要写 |
| `d` | 建卡日期 |

## 写卡片的规矩（给人，也给代写的模型）

- 用完整的句子写，三个月后冷读也能看懂。一张卡一个想法。
- 不用符号（→ = × /）代替动词，不叠括号，自造的词第一次出现时用几个字解释。
- `lit` 卡先写作者的主张；自己的读法另起一段，以“我的读法：”开头。
- `perm` 卡只收 Alta 自己说过的立场。模型的建议她没有明确采纳的，不算她的。
- 页码和引文不确定就不写，或标〔待核〕。每个出处最多一句短引文。
- 标签 `待读`：对话里别人推荐、她还没接的线索。
